# 🎮 Hammy2.fun - Unblocked Games Portal

A retro-inspired unblocked games website with a Kiwi app-style interface featuring open-source PC games.

## ✨ Features

- **Kiwi App-Inspired UI** - Clean, modern design based on the popular Kiwi browser app
- **Orange & Pink Neon Theme** - Eye-catching orange and pink gradient color scheme
- **6 Open-Source Games** - Featured games with direct links to official sites and repositories
- **Search Functionality** - Quickly find games using the search bar
- **Live Clock** - Display current time, temperature, ping, and battery status
- **Color Wheel** - Randomize card colors for a fun interactive experience
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Animated Particles** - Beautiful orange and pink particle effects in the background

## 🚀 Getting Started

### Option 1: Local Testing
1. Clone the repository:
   ```bash
   git clone https://github.com/trentontice808-pixel/hammy2-fun.git
   cd hammy2-fun
   ```

2. Open `index.html` in your browser (double-click the file)

### Option 2: Live Deployment (GitHub Pages)
1. Go to repository settings
2. Navigate to Pages section
3. Select `main` branch as source
4. Save changes
5. Your site will be live at: `https://trentontice808-pixel.github.io/hammy2-fun/`

### Option 3: Live Server (VS Code)
1. Install the "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"

## 🔧 Customization

### Adding More Games
Edit `script.js` and add to the `games` array:

```javascript
{
    name: 'Game Name',
    genre: 'Genre',
    url: 'https://official-website.com/',
    github: 'https://github.com/owner/repo',
    color1: '#FF9500',
    color2: '#FFB6D9'
}
```

### Changing Colors
Modify the color values in `styles.css`:
- `.stat-box` - Stat boxes color
- `.search-box` - Search bar color
- `.game-card` - Card backgrounds
- Body gradient - Background colors
